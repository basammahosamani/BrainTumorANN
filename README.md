# Brain Tumor Classification using ANN

Team Name:
ML Mavericks

Project Description:
This project classifies Brain MRI images into four categories using an Artificial Neural Network (ANN).

Classes:
1. Glioma
2. Meningioma
3. No Tumor
4. Pituitary

Software:
Python
TensorFlow
Streamlit

Run the project:

python train_model.py

Run the application:

streamlit run app.py
